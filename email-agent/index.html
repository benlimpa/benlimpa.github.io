Email Agent

Previewed, undoable mailbox sweeps from the terminal.

Email Agent is a local command-line tool I use to synchronize and organize my own Gmail accounts. It keeps the working copy on my computer, where I can search messages and review a proposed sweep before anything moves.

What it does

  • Pulls mailbox messages into a local Maildir and search index.
  • Shows a grouped preview before moving messages between folders.
  • Keeps a manifest so user-directed moves can be undone.
  • Does not send email or permanently delete messages.
